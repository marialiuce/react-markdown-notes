> A fully functional Markdown note-taking application built with React. It features a responsive layout, live markdown preview, and data persistence using LocalStorage.

## Live Demo

**[Click here to try the application](https://react-markdown-notes-tan.vercel.app/)**

## Features

- **Create Notes**: Add new notes to your collection easily.
- **Live Preview**: Type markdown on the left and see the rendered result instantly on the right.
- **Update & Edit**: Seamless editing experience with immediate feedback.
- **Delete**: Remove unwanted notes with a single click.
- **Persistence**: All data is saved in the browser's LocalStorage, so you never lose your work even if you refresh the page.
- **Responsive Design**: Works on desktop and mobile.

## Technologies Used

- **React.js**: For building the user interface.
- **Vite**: For fast development and building.
- **React Markdown**: To render markdown content safely.
- **CSS3**: For custom styling and layout (Flexbox).
- **LocalStorage API**: For data persistence.
